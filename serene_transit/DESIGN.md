# Design System --- ANANTALIA TRANS

## 1. Brand Tokens & Colors
- Primary Teal: #079F9A
- Dark Teal: #087F7B
- Sage Accent: #A3B8A1
- Surface Mint: #EAF6F4
- Surface Page: #F7F8F6
- Surface Card: #FFFFFF
- Text Primary: #173332
- Text Secondary: #526765
- Border Subtle: #DCE5E2
- WhatsApp Green: #25D366

## 2. Typography
- Headings & Body: Inter / Manrope / DM Sans, font-sans
- Display H1: 44px - 56px, bold, tracking-tight
- Section H2: 32px - 40px, bold
- Card H3: 20px - 24px, semibold
- Body: 16px, line-height 1.6
- Caption / Small: 13px - 14px

## 3. Visual Language & Elevation
- Editorial photography with restrained shadows (shadow-sm to shadow-md)
- Rounded cards: rounded-2xl
- Purposeful whitespace, clear data grouping
- Clean bullet lists for fleet specifications
- Discrepancy notice & missing data state styling: subtle amber/neutral badge

## 4. Motion System (Balanced / Seimbang)
- Transitions: 200ms - 350ms ease-out
- Staggered hero entrance
- Accordion expand/collapse transitions
- Tab and fleet filter state changes
