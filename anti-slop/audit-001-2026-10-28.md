# Audit UI/UX ANANTALIA TRANS

Tanggal pemeriksaan: 28 Oktober 2026  
Mode audit: After. Temuan berikut menunggu persetujuan nomor sebelum perbaikan UI.  
Cakupan: kode statis pada lima halaman kerja, CSS/JavaScript lokal, `fleet.json`, dokumentasi, dan daftar berkas workspace.

## A. Ringkasan eksekutif

### Kekuatan

- Lima halaman kerja tersedia: Beranda, Tentang Kami, Layanan, Armada, dan Pusat Bantuan. Navigasi lokal dan logo root `logo.png` dipakai pada kelima halaman.
- Menu mobile dan tombol kembali ke atas terpusat di `js/site-shell.js`. Modal detail Layanan dan Armada memiliki tombol tutup, dukungan Escape, dan aksi WhatsApp. Pusat Bantuan memiliki FAQ, peta titik layanan, filter, pencarian, dan modal detail.
- Dukungan `prefers-reduced-motion` tersedia pada CSS bersama dan CSS Armada. Dialog utama menggunakan transisi dalam kisaran 160–220 ms.
- Validator statis aktual lulus: lima halaman, shell, logo/path lokal, fragmen, ID unik, keseimbangan CSS, dan sintaks JavaScript.

### Masalah terbesar

- Detail armada dan tarif pada halaman Armada tidak punya sumber data yang terverifikasi. `fleet.json` menyatakan `isDummy: true`, 63 data armada berstatus pending, dan sebagian besar kolom spesifikasi/tarif kosong; halaman Armada tetap menampilkan tarif, kapasitas, tahun, serta status “Siap Jalan”.
- Teks putih pada latar `#25D366` memiliki rasio kontras sekitar 1,98:1, di bawah WCAG AA untuk teks normal maupun besar.
- Filter wilayah dan pencarian Pusat Bantuan mengatur visibilitas pin secara terpisah. Mengetik pencarian setelah memilih wilayah dapat menampilkan kembali pin dari wilayah lain; daftar lokasi tidak ikut dicari dan tidak ada pesan hasil kosong.
- Tombol “Kembali ke atas” menghapus outline fokus tanpa pengganti `focus-visible` yang jelas pada kelima halaman.
- Workspace saat ini tidak memuat ekspor `code.html`/`screen.png` atau file frame Stitch. Audit struktur frame, duplikasi versi, overlap antarfame, dan prototype hanya bisa dilakukan sebagian dari HTML kerja.

### Lima prioritas

1. **Temuan 01, P0:** verifikasi tarif, ketersediaan, kapasitas, tahun, dan spesifikasi Armada sebelum informasi itu dianggap data publik.
2. **Temuan 02, P0:** ubah pasangan warna tombol WhatsApp agar labelnya memenuhi kontras AA.
3. **Temuan 03, P1:** satukan logika filter dan pencarian Pusat Bantuan serta tambahkan status hasil kosong yang dapat dibaca.
4. **Temuan 04, P1:** pulihkan indikator fokus keyboard untuk tombol kembali ke atas di semua halaman.
5. **Temuan 05–06, P1:** verifikasi klaim cakupan wilayah/kontak dan pulihkan sumber frame agar audit visual serta prototype bisa dibandingkan dengan desain asli.

## D. Audit animasi

### Baik / punya tujuan yang jelas

- Menu mobile berubah status terbuka/tertutup, menangani Escape dan klik luar di `js/site-shell.js`.
- Modal detail Layanan/Armada memakai transisi pendek, memiliki state penutupan, dan mendukung `prefers-reduced-motion`.
- Modal lokasi Pusat Bantuan memakai fade/translate ringan dan memulihkan fokus; FAQ memperbarui `aria-expanded` saat dibuka/ditutup.
- CSS global dan Armada menyediakan aturan pengurangan motion.

### Perlu diperbaiki atau ditinjau

- Hover foto Tentang Kami/Armada memakai skala dan durasi 700 ms. Ini hanya masukan pointer; cek dampak crop, performa, serta fallback tanpa hover pada sentuh.
- `will-change` dipakai pada beberapa kelas interaksi yang dapat diterapkan ke banyak elemen (`.motion-card`, `.motion-chip`, `.faq-content`, `.city-marker`). Pastikan hanya dipertahankan bila profiling menunjukkan manfaat.
- Modal cabang memiliki 220 ms, sedangkan CSS modal detail lainnya sekitar 220 ms; penutupan handler JavaScript memakai timer 170 ms. Perbedaan 50 ms berpotensi membuat penutupan terasa terpotong, perlu dicocokkan melalui browser.
- WhatsApp pulse/shimmer berulang tercantum di CSS. `prefers-reduced-motion` menonaktifkan pulse dan memendekkan animasi/transisi, tetapi durasi infinite perlu diuji dampaknya secara visual.
- Scrollbar WebKit global tersembunyi, sehingga affordance panel yang memiliki scroll bisa berkurang.

### Mencurigakan, belum bisa dinyatakan cacat visual

- Efek hover gradien pada foto tidak terlihat pada layar sentuh.
- Modal peta dibuat sebagai `div[role=dialog]`, bukan `<dialog>` native; fokus dan backdrop dikendalikan manual. Kode menyediakan Escape, fokus, dan trap Tab, tetapi urutan fokus, zoom, dan scroll belum diuji di Chrome.
- Tidak ada uji layout shift/flicker atau perbandingan timing motion di browser saat audit ini.

### Rekomendasi motion system

Pertahankan skala saat ini sebagai dasar: micro-interaction 150–200 ms, state komponen 180–240 ms, dialog 200–280 ms, reveal sekitar 380 ms. Samakan timer JS dengan CSS, batasi `will-change`, pertahankan state fokus/pressed tanpa hover, dan verifikasi reduced motion pada setiap dialog. Angka ini rekomendasi audit, belum diterapkan.

## F. Batasan dan hasil yang dapat dipastikan

### Fakta yang diperiksa pada sesi ini

- Workspace aktif berisi lima halaman HTML, file CSS/JS lokal, `fleet.json`, `logo.png`, dokumentasi, dan `serene_transit/DESIGN.md`.
- Tidak ada folder/file ekspor Stitch, `code.html`, atau `screen.png` pada daftar berkas saat ini.
- `fleet.json` menyatakan `isDummy: true` dan 63 entri; halaman Armada memiliki enam kartu HTML dengan nilai yang perlu diverifikasi.
- Pusat Bantuan memiliki 22 pin, satu `data-verified="true"` dan 21 `false`, sembilan item daftar lokasi.
- Validator dijalankan pada sesi ini dan lulus.
- Browser inventory pada sesi ini tidak menyediakan Google Chrome. Sesuai preferensi pengguna sebelumnya, Brave tidak digunakan sebagai pengganti Chrome.

### Dugaan / perlu konfirmasi

- Kebenaran nomor WhatsApp, alamat, email, badan hukum, harga, kapasitas, ketersediaan, persentase 99,4%, klaim inspeksi 25 titik, serta cakupan rute belum bisa dipastikan dari sumber resmi dalam workspace.
- Label “Pending Owner Review” dan `data-verified=false` menunjukkan sejumlah data menunggu pemeriksaan, tetapi tidak menjelaskan status legal/operasional sebenarnya.
- Kegagalan Tailwind CDN yang dicatat di dokumen sebelumnya dapat menyebabkan layout tidak terbentuk pada kondisi serupa; reproduksi browser tidak dilakukan saat audit ini.

### Tidak dapat diverifikasi pada sesi ini

- Frame/versi ekspor, alur prototype lengkap, dan perbandingan desain Stitch.
- Visual aktual pada 1440, 1366, 768, dan 390 px; overlap, overflow, crop foto, dan tampilan ikon/font.
- Interaksi browser terkini, console error, WhatsApp eksternal, performa, validasi formal HTML/CSS, kontras semua pasangan warna, zoom 200%, serta reduced-motion di browser.
- Kinerja CDN dan URL gambar eksternal dari jaringan pengguna.

### Pemeriksaan eksekusi

- `powershell -NoProfile -ExecutionPolicy Bypass -File tests\validate.ps1`: **LULUS**. Validator melaporkan lima halaman, shell navigasi, logo/path lokal, target fragmen, ID unik, CSS seimbang, dan sintaks JavaScript.
- Chrome desktop/mobile pada viewport 1440 × 900, 1366 × 768, 768 × 1024, dan 390 × 844: **tidak diuji dalam sesi ini**.
- File aplikasi, logo, design system, dan ekspor Stitch tidak diubah selama audit. Satu file laporan ini dibuat untuk mendokumentasikan temuan.
